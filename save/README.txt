STARTER SAVE  --  Marvel's Spider-Man 2 Archipelago

Archipelago needs the open world: every district reachable, every side mission
available, nothing collected yet. A brand-new game does not have that -- the
story hands the city out piece by piece -- so the client ships a save that does:

    slot2-manual-0.save     56 side missions available, 0 done
                            1/42 spider-bots, 1/23 photo ops (the story's own)

HOW TO INSTALL IT

1. Close the game.
2. Open your save folder:
       %USERPROFILE%\Documents\Marvel's Spider-Man 2\<a long number>   (on some PCs Documents lives under OneDrive -- the game follows it)
3. BACK UP anything already called slot2-*.save -- this replaces save slot 2.
4. Copy slot2-manual-0.save in.
5. Start the game, load slot 2. That is your Archipelago file.

If you would rather keep your own slot 2: this save has only ever been tested
in slot 2. Renaming it to slot3-manual-0.save may work; if the game does not
list it, use slot 2.

The file contains game progress only -- no account name, no Steam ID.
